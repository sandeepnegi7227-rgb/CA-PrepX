# CA PrepX

Study planner, ICAI RTP/MTP tracker and MCQ practice for CA students.
Static site on Vercel + Supabase for sign-in and saved progress.

| File | What it is |
|---|---|
| index.html | The website |
| admin.html | Your private dashboard at /admin |
| config.js | Your Supabase URL and key |
| supabase-setup.sql | Run once in Supabase to create the tables |
| vercel.json, favicon.svg | Vercel settings and site icon |

If config.js is left empty, the site still works with progress saved on the device only.
